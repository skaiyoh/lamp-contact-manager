# LAMP Contact Manager

A contact management web application built on a LAMP stack. Users can create an
account, sign in, and manage a personal list of contacts through a frontend that
communicates with the backend through an API.

## Planned Functionality

- User registration and login
- Contact creation, viewing, editing, and deletion
- Contact search
- API-based communication between the frontend and backend
- Remote server deployment

## Contact Records

Each contact record must include at least:

- First and last name
- Email address
- Phone number
- Date created

## Technical Requirements

- Use a LAMP stack: Linux, Apache, MySQL, and PHP
- Expose backend functionality through API endpoints
- Demonstrate at least one API endpoint with SwaggerHub

## Presentation Requirements

The final presentation must include:

- Professional PowerPoint slides
- A working demo with login, registration, CRUD operations, and search
- Substantial participation from every team member
- A use case diagram
- A Gantt chart
- An entity relationship diagram
- A SwaggerHub API demonstration
